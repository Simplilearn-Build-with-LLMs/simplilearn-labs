# Lab 03 A: Inbox to Appointment

Build an assistant that takes an already classified customer email and calls the correct calendar function. A missing detail or an impossible time should end as a clarification, with the calendar unchanged.

## Files
| File | What it is |
|---|---|
| `inbox_to_appointment.ipynb` | The lab notebook. |
| `lab_data/` | The calendar, nine emails, and the expected outcome for each email. |

## Before you start
1. If this is your first session, do the one-time setup in the repo's `README.md`.
2. Run cell 1 of `START_HERE.ipynb` to make sure you have the latest version.
3. Open this notebook, check the kernel (top right) says **.venv**, and run the cells in order. `lab_data` sits beside the notebook.

Write the tool descriptions in 6.1 and the missing-date email in 7.1 before you run those cells. Model: `gpt-4.1-mini`. Do not paste your API key into the notebook.
